# 🗺️ OpenStreetMap (OSM) Spatial Extraction & Processing

[![OSM](https://img.shields.io/badge/OpenStreetMap-Data%20Mining-green?logo=openstreetmap)](https://www.openstreetmap.org/)
[![GeoPandas](https://img.shields.io/badge/GeoPandas-Spatial%20Joins-blue)](https://geopandas.org/)

### Overview
Automated querying and extraction of spatial primitives (nodes, ways, relations) from the OpenStreetMap global database using the Overpass API and OSMnx. Focuses on urban building footprints, road centreline networks, and healthcare point-of-interest (POI) infrastructure across Ghana.
