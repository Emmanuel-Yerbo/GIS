# 🛣️ Accra Road Network & Graph Topology Analysis

[![OSMnx](https://img.shields.io/badge/OSMnx-Road%20Networks-blue)](https://osmnx.readthedocs.io/)
[![NetworkX](https://img.shields.io/badge/NetworkX-Graph%20Analytics-orange)](https://networkx.org/)

### Overview
Extracts and analyzes road networks across the Greater Accra Metropolitan Area from OpenStreetMap using **OSMnx** and **NetworkX**.
- **Topological Edge Extraction**: Captures motorways, trunk roads, primary corridors, and secondary residential connectors.
- **Network Centrality**: Calculates node betweenness centrality, degree distribution, and circuity metrics to identify transit bottlenecks and single-point-of-failure bridges.
